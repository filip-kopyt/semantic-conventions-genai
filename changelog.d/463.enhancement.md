Add `gen_ai.skill.*` attributes and skill metrics for agents that use [Agent Skills](https://agentskills.io). Skill loads, resource reads and script runs are recorded on the `execute_tool` span; the skills whose instructions are in an invocation's context, and whether each one is compacted, are recorded on the invoke agent span as `gen_ai.skills`. New metrics count loads and script runs, and report how many distinct skills a single agent or workflow invocation activated.
